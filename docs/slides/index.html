THE SOLUTION

Managed Entitlements

Subscribe to a Bedrock model once. Distribute the license to every account in your org through AWS License Manager. No repeat subscriptions needed.

Centralized management
One subscription, one license. See all model access from a single pane in License Manager.
Org-wide distribution
Grant to your entire Organization ID. New accounts automatically inherit access.
Compliance-friendly
Clear audit trail of who has access, when it was granted, and by whom.
Revoke anytime
Delete a grant to instantly remove access. Fine-grained control per account or org-wide.

PERMISSIONS

Make sure you have the right permissions

Procurement fast path
AWSMarketplaceManageSubscriptions
Attach the AWS managed policy so procurement can accept the private offer in Marketplace. No custom JSON needed for the subscription step.
Use this first
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "LicenseAdminSetupAndGrants",
      "Effect": "Allow", "Resource": "*",
      "Action": [
        "organizations:DescribeOrganization",
        "organizations:EnableAWSServiceAccess",
        "organizations:ListAWSServiceAccessForOrganization",
        "license-manager:GetServiceSettings",
        "license-manager:UpdateServiceSettings",
        "license-manager:ListReceivedLicenses",
        "license-manager:AcceptGrant",
        "license-manager:GetLicense",
        "license-manager:GetLicenseUsage",
        "license-manager:ListDistributedGrants",
        "license-manager:GetGrant",
        "license-manager:CreateGrant",
        "license-manager:CreateGrantVersion",
        "license-manager:DeleteGrant",
        "iam:CreateServiceLinkedRole"
      ]
    }
  ]
}
Granular admin policy
Use custom IAM for the org / license administrator in the management account, or a delegated member account. This role runs the one-time enablement, then creates and activates grants.
Activation needs both read and write access. Add AcceptGrant, GetLicense, and GetLicenseUsage; CreateGrantVersion performs the activation.
Resource is "*" because licenses and grants don't exist until Marketplace creates them. Scope by who you attach the role to. Delegating? The management account also needs organizations:RegisterDelegatedAdministrator. Everything lives in us-east-1 - don't region-lock it.

FAQ

Common questions

Is a subscription per model?
Yes. Each model requires its own Marketplace subscription. Each subscription creates a separate license you can distribute independently.
What about new accounts?
Org-wide grants auto-cover new member accounts. Individual grants require manual creation for each new account.
Can I revoke access?
Yes. Delete the grant anytime - the recipient immediately loses access to invoke the model.
How long does distribution take?
Minutes for individual accounts. Up to several hours for large Organizations with many member accounts.
Can I share outside my org?
No. Managed Entitlements only works within your AWS Organization boundary.
What about existing subscriptions?
Today this supports new subscriptions only (post Oct 30, 2025). Existing subscription support is on the roadmap.
